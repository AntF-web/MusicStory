HOW IT WORKS

  1. Edit everything here. Changes autosave locally.
  2. Use Preview Site to see the draft in the real design.
  3. When ready, download site-data.js.
  4. Replace the existing site-data.js in your GitHub repository and commit/push.

Privacy note: GitHub Pages is static hosting. This editor page is not linked from the public site, is marked noindex, and can be PIN-locked in your browser, but anyone who knows the URL can still download the page source. For truly authenticated editing, a server/CMS would be required.
